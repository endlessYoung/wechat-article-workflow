# 为什么你总是坚持不下去

你有没有过这样的时刻:下定决心要读书、健身、学英语,结果坚持了三天就放弃了?这不是你意志力差,而是方法从一开始就错了。

很多人以为,坚持靠的是自律。但心理学研究发现,真正能长期坚持的人,靠的都不是意志力,而是把行为变成习惯,让系统替你做决定。本文会讲清楚三件事:习惯为什么比自律更可靠、如何设计一个不会失败的习惯、以及如何应对中断和反弹。这三件事,每一件都值得单独展开,但今天我们先用一篇文章把它们串起来,让你读完就能直接上手。

## 01|习惯的复利效应

先说一个反直觉的事实:每天进步1%,一年后你会强大37倍;每天退步1%,一年后你会几乎归零。

这就是复利效应。习惯是自我提高的复利——你今天的每个小动作,都在为十年后的自己投票。

> 人们容易高估决定性的时刻,却容易低估每天微小的改进。

### 复利为什么难以坚持

问题在于:复利前期增长极慢,肉眼几乎看不到变化。大多数人恰恰是在"看不到回报"的阶段放弃的。

## 02|设计一个不会失败的习惯

理解原理之后,真正的问题来了:具体怎么做?下面两个法则,能帮你把习惯真正立起来。

### 法则一:两分钟原则

把新习惯压缩到两分钟以内。想健身?先换上运动服。想读书?先翻开书读一页。用代码表示,就是:

```python
def start():
    # 两分钟原则:先做两分钟
    return "先做两分钟"
```

### 法则二:绑定已有习惯

把新习惯挂在旧习惯后面。比如:每天泡完咖啡后,写下当天最重要的三件事。具体来说,可以这样安排:

- 早上:先写两分钟
- 中午:复盘三件事
- 晚上:记录一条心得

---

## 03|如何应对中断

再完善的计划,也会被意外打乱。出差、加班、生病,任何一个都能打断你。关键在于,你如何对待中断本身。

### 关键是"不要错过两次"

错过一次是意外,错过两次就是新习惯的开始。落地路径其实只有三步:

1. 选择一个最小习惯
2. 挂到已有行为后面
3. 连续执行21天

## 结尾:从今天开始

别等一个完美的时机。今天,就从两分钟开始。
