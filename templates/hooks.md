# 模板：开头钩子（hooks）

> 用途：文章开头 3 行内抓住读者。**选一个方向，结合文章主题改写**，不要照抄。

## 1. 痛点式

```
你有没有过这样的时刻：明明下定了决心，却在第三天就悄悄放弃了？
```

```
不是方法不够多，而是你缺一套【主题】的底层逻辑。
```

## 2. 场景式

```
周末的晚上，朋友发来一条消息："你那个方法真的有用吗？"
```

```
凌晨一点，你还在刷手机。不是不困，是白天过得太空。
```

## 3. 提问式

```
如果只能保留一个习惯，你会选哪一个？想清楚再往下读。
```

```
你有没有算过，自己一天里真正"专注"的时间有多少？
```

## 4. 反常识 / 数据式

```
一个看似普通的动作，重复一百次，结果可能完全不同。
```

```
每天进步 1%，一年后你会强大 37 倍；每天退步 1%，一年后几乎归零。
```

## 5. 故事式

```
三年前，我差点放弃写作。后来我想明白了一件小事。
```

## 使用要点

- 钩子必须与主题强相关：写习惯养成的文章，不要用"我差点放弃写作"当开头。
- 钩子之后 1-2 句内点明"这篇文章讲什么、对读者有什么用"。
- 控制长度：钩子 1-3 行，超过 3 行就是铺垫过长。
