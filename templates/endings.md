# 模板：结尾与 CTA（endings）

> 用途：给读者一个"能带走的东西"。至少完成下面四件事之一；可组合使用。

## 1. 收束式（2-3 句总结，不是复述目录）

```
把全文串起来就三句话：习惯比自律更可靠；把新习惯压缩到两分钟；中断了，也绝不错过两次。
```

## 2. 行动号召式（今天就能做的具体动作）

```
别等一个完美的时机。今天，就从最小的一步开始——现在，只做两分钟。
```

```
看完这篇文章，选一个习惯，今晚就执行一次，然后明天在留言区告诉我结果。
```

## 3. 金句收尾式（可截图分享的一句话）

```
你今天的每个小动作，都在为十年后的自己投票。
```

```
坚持不是一次惊天动地的决定，而是每天一个不起眼的重复。
```

## 4. 互动式（开放问题）

```
你最近想养成什么习惯？或者，你曾经成功坚持过什么？欢迎在留言区聊聊。
```

```
如果这篇文章对你有用，欢迎转发给需要的朋友。
```

## 使用要点

- 结尾避免"空洞升华"（"让我们一起努力"）和目录式复述。
- 行动号召要具体到"今天、几分钟、做什么"，越具体越可能被执行。
- 互动问题要开放、好回答；避免"你觉得呢？"这种没有着力点的问题。
- 关注/转发引导遵守平台规范，避免过度诱导（"不转不是中国人"绝对禁止）。
