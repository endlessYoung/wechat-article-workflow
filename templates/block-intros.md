# 模板：块引导语（block-intros）

> 用途：在列表、引用、代码块等"块"前面加一句话，告诉读者"接下来会看到什么"，避免突兀。

## 1. 列表引导语

```
主要有三点：
```

```
落地路径其实只有三步：
```

```
你只需要记住两个原则：
```

## 2. 引用引导语

```
作家 XX 曾说：
```

```
关于这一点，原文是这样说的：
```

```
《书名》里有一段话，一直很打动我：
```

## 3. 代码引导语

```
核心逻辑如下：
```

```
用代码表示，就是：
```

```
关键就这一行：
```

## 4. 图片 / 图表引导语（预留）

```
看这张图更直观：
```

```
（图）图注：一句话说明图里最重要的信息
```

## 使用要点

- 引导语要"承上启下"：承接前文语境，预告块的内容类型。
- 列表引导语里可以带上数量（"三点/两步"），给读者预期。
- 引用引导语务必接**真实的出处**，不要留 XX 占位符。
- 引导语本身 ≤ 20 字，别让引导语比内容还长。
