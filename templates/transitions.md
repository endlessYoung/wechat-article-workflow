# 模板：章节过渡句（transitions）

> 用途：在章节/话题切换处"承上启下"，降低读者流失。**必须结合上下文改写**，保留句式、替换内容。

## 1. 承接式（上一节讲了原理，本节讲做法）

```
理解了背景，我们再来看看具体应该怎么做。
```

```
讲完了"是什么"，接下来聊聊"怎么做"。
```

## 2. 转折式（从普遍认知转到反常识/关键差异）

```
道理都懂，但真正拉开差距的，是执行。
```

```
到这里你可能觉得都知道了——但少做一步，前面全白搭。
```

## 3. 提问式（自然引出下一节）

```
那么，具体该怎么落地呢？下面给你一套可操作的方法。
```

```
问题来了：为什么明明知道，却总是做不到？
```

## 4. 并列式（同一主题的另一个维度）

```
除了方法本身，还有一个常被忽略的因素。
```

```
方法解决了"会不会"，接下来解决"能不能坚持"。
```

## 5. 总结预告式（长文分节）

```
到这里，核心思路已经清晰了，最后再补一个关键细节。
```

```
第一部分到此结束。下一部分，我们聊聊最常见的三个坑。
```

## 使用要点

- 过渡句 ≤ 30 字，一句话完成"承上 + 启下"。
- 每 2-3 个章节插一次即可；小标题（H3）之间一般不需要。
- 把模板里的占位内容换成你文章的实际内容，比如"方法解决了'会不会'，接下来解决'能不能坚持'"里的"方法/坚持"要对应你的章节。
