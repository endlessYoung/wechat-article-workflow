## 二、问题解决实录

### 「一键复制」是怎么啃下来的（核心案例）

1. base64 内嵌 → 公众号编辑器丢弃 ❌
2. 本地文件路径 → 图片裂开 ❌
3. 定位根因：公众号要的是「它服务器能访问的公网 URL」，拆成三个子问题：
   - 图怎么读 → OCR（模型和子代理都没视觉）
   - 图放哪 → GitHub 图床 + jsDelivr CDN（国内可访问）
   - 怎么复制 → `execCommand('copy')` 复制富文本 + 按钮页
4. 收尾：jsDelivr 首次 301 → curl 预热，全部转 200

结果：`article-copy.html`，点按钮 → 粘贴，图片自动加载。

### 其它坑（一句话一个）

- 列表空行后类型误合并 → 加类型判断
- `"Segoe UI"` 双引号截断 `style` 属性 → 样式值统一转义
- sharp 重编码反而变大 → 换调色板量化（palette）
- OCR 的 traineddata 污染仓库 → 加进 `.gitignore`
- 本地文件夹重命名被锁 → 需关掉会话再手动改

### 通用套路

定位卡点 → 拆成小问题 → 换方向 → 留可验证结果。

## 三、结论

「是不是 AI 写的」是伪命题；「怎么用 AI、卡住了怎么一步步拆开解决」才是真功夫。这个仓库就是这套方法的产物。
