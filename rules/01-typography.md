# 规则 01：标点、空格、数字与强调

## 1. 标点全角化

中文语境下，标点一律使用全角：

| 半角（错误） | 全角（正确） |
| --- | --- |
| `,` | `，` |
| `.` | `。` |
| `?` | `？` |
| `!` | `！` |
| `:` | `：` |
| `;` | `；` |
| `( )` | `（ ）` |

注意事项：

- 仅在中英文混排的**中文语境**中转换；纯英文句子、代码、URL、版本号（`v1.2.0`）、小数（`3.5`）保持半角。
- 省略号用 `……`（两个字符），不要用 `。。。` 或 `...`。
- 引号：中文正文优先使用「」或“ ”，全篇统一一种；引号内再次引用时用内层引号。
- 破折号用 `——`（两个连字符宽度的中文破折号），不要用单个 `-` 或 `--` 代替。

## 2. 中英文/数字之间加空格

中文与西文（字母、数字）之间加一个半角空格，提升扫读清晰度：

- 错误：`每天进步1%`、`使用Python实现`、`第3章`
- 正确：`每天进步 1%`、`使用 Python 实现`、`第 3 章`

例外：

- 代码、行内代码、URL、变量名内部不加空格（如 `README.md`、`http://x.com/a`）。
- 中文与中文标点之间不加空格。

## 3. 数字与单位

- 数字与中文单位之间加空格：`21 天`、`500 元`、`3 次`。
- 百分号与中文之间加空格：`提升 50%`。
- 千分位、小数、日期、版本号按原文保留：`1,000`、`3.5`、`2025-01-01`、`v2.0`。

## 4. 强调

- **加粗**：只用于关键结论、核心观点、行动指令；一屏（约 3-5 段）不超过 2-3 处，否则等于没有强调。
- **斜体**：公众号正文慎用（手机端辨识度低），可用于英文书名等。
- **下划线 / 颜色**：正文基本不用；需要时在后台用编辑器样式，不要用 markdown 下划线。
- 强调要"整句"而非"整段"：加粗一个短句（≤ 20 字）比加粗一整段更有效。

## 5. 常见错误清单

- [ ] 句末半角句号 `.`
- [ ] 中文后紧跟英文/数字没有空格
- [ ] 连续感叹号 `！！` / 感叹号加问号 `？！`（情绪化表达，慎用）
- [ ] 省略号用三个点 `...`
- [ ] 全文引号样式不统一
- [ ] 一整段加粗
