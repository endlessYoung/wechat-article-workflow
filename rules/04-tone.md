# 规则 04：引导文案、过渡句与情绪节奏

> 规则 01-03 解决"看得清"，本规则解决"读得下去"。这是 Agent 的创作主场：模板素材见 `templates/`，此处是原则。

## 1. 开头：3 行内进入主题

- 开头决定读者是否继续读。**前 3 行必须让读者知道"这篇文章跟我有什么关系"**。
- 常见钩子类型（模板见 `templates/hooks.md`）：
  - 痛点式：描述读者正在经历的具体困扰
  - 场景式：一个具体的画面/对话
  - 提问式：一个让读者忍不住想答案的问题
  - 反常识式：先抛一个反直觉的结论
- 开头禁忌：客套话（"大家好"）、大段背景铺垫、标题党式悬念。
- 开头与文章标题呼应：标题承诺了什么，开头 3 行内就要兑现。

## 2. 过渡句：每 2-3 个章节一次

- 章节切换是读者流失的高发点：上一节讲完，读者可能觉得"够了"。
- 过渡句的作用：**承接上文 + 预告下文 + 给出继续读的理由**。
- 模板见 `templates/transitions.md`，但**必须结合上下文改写**：
  - 承接式：`讲完了"是什么"，我们来看看"怎么做"。`
  - 转折式：`道理都懂，但真正拉开差距的，是执行。`
  - 提问式：`那么，具体该怎么落地呢？`
- 过渡句要短（≤ 30 字），一句话完成"承上启下"。

## 3. 结尾：给读者一个"带走的东西"

- 结尾至少做一件事（模板见 `templates/endings.md`）：
  - 收束：用 2-3 句话总结全文核心（不是复述目录）
  - 行动号召：给一个今天就能做的具体动作
  - 金句收尾：一句可以截图分享的话
  - 互动：一个开放问题（"你最近想养成什么习惯？"）
- 结尾禁忌：突然结束、空洞升华（"让我们一起努力吧"）、过度诱导关注。

## 4. 情绪与语气

- **真诚、克制、有分寸**：像写给一位朋友，而不是喊口号。
- 少用：感叹号连用、网络烂梗、空话套话、堆砌形容词（"非常极其特别"）。
- 允许：第一人称视角、具体细节、自嘲。
- 信息密度优先：能用一个具体例子说明的，不用三个抽象形容词。

## 5. 每节内部的小节奏

- 一节之内：**观点 → 论证/例子 → 小结** 的循环，每循环 1-3 段。
- 一节结束处放一个"记忆点"（加粗句或金句），方便读者回看时快速定位。
- 长文（> 2000 字）务必给读者"进度感"：章节编号、阶段性小结。

## 6. 常见错误清单

- [ ] 开头 3 行还在铺垫，没进入主题
- [ ] 章节之间生硬切换，无过渡
- [ ] 结尾只列了目录式总结
- [ ] 全篇语气忽冷忽热，风格不统一
- [ ] 模板句未改写，读起来像"AI 味"太重
