# 规则 02：标题层级、段落节奏与留白

## 1. 标题层级（H1-H3）

- **H1**：文章主题或大章节。公众号正文建议最多使用到 H2/H3；若文章较长，可用 H1 做大章节、H2 做小节。
- **H2**：小节标题，一篇文章 3-7 个为宜。
- **H3**：小节内的要点标题，仅在确有细分必要时使用；避免 H3 套 H3。
- 正文层级**不超过 3 层**；层级越多，读者越容易迷路。

标题规范：

- 同级标题风格统一。可选风格（全篇选一种）：
  - 数字式：`01 | 习惯的复利效应`、`02 | 设计一个不会失败的习惯`
  - 中文序号式：`一、习惯的复利效应`
  - 纯文本式：不加序号，靠字号层级区分
- 标题与正文之间、标题与标题之间**空一行**（机器排版时引擎保证）。
- 标题是"路标"，应能独立读懂：把标题连起来读，应该就是文章的骨架。
- 避免标题党：标题要诚实反映内容。

## 2. 段落节奏

- **单段 1-4 行**，手机屏幕约 3-4 行即换段；单段正文**不超过 120-160 字**。
- 一个段落只讲一个信息点；讲完就换段。
- 长短句交替：连续短句制造节奏，长句只在需要完整表达复杂关系时使用。
- 段落开头避免"首先/其次/再次/最后"的流水账连接；用内容本身推进。

## 3. 留白

- 段与段之间空一行（引擎默认保证）。
- 标题、列表、引用、代码块、分隔线前后各空一行。
- 列表项之间：短列表（2-4 项）不加空行；长列表（>5 项）可每 2-3 项分组。
- 图片（如有）与正文之间空一行，图下加一行图注。

## 4. 每屏节奏（约 3-5 段）

每 3-5 段安排一个"呼吸点"：

- 一个金句 / 要点句（可加粗）
- 一个引用
- 一个列表
- 一个小标题
- 一个分隔线

让读者每滑一屏都能"抓住点什么"，是提高完读率的关键。

## 5. 常见错误清单

- [ ] 一段超过 5 行 / 160 字
- [ ] 标题层级跳级（H1 直接到 H3）
- [ ] 相邻两个标题之间没有正文（需要补一句过渡）
- [ ] 全篇无标题、无列表、无引用，纯文字墙
- [ ] 标题带句号
- [ ] 用加粗冒充标题（应使用真实标题层级）
